# Настройка официального Telegram Gateway API

Telegram Gateway - это официальный сервис от Telegram для отправки кодов авторизации через официальный канал Telegram. Стоимость: **~$0.01 (1-2 рубля) за сообщение**.

## Что такое Telegram Gateway?

Telegram Gateway позволяет отправлять коды авторизации пользователям через официальный канал Telegram. Пользователь получает SMS/сообщение от официального канала Telegram, а не от вашего бота.

**Преимущества:**
- ✅ Не нужно создавать своего бота
- ✅ Официальный канал Telegram (высокое доверие)
- ✅ Быстрая доставка
- ✅ Низкая стоимость (~1-2 рубля за сообщение)
- ✅ Безопасность на уровне Telegram

## Шаг 1: Регистрация в Telegram Gateway

1. Перейдите на официальный сайт: https://core.telegram.org/gateway
2. Зарегистрируйте аккаунт
3. Подтвердите email и телефон
4. Пополните баланс (минимальная сумма обычно $10-20)

## Шаг 2: Получение API ключа

1. В личном кабинете Telegram Gateway перейдите в раздел "API"
2. Создайте новый API ключ
3. Скопируйте:
   - **API Key** (публичный ключ)
   - **API Secret** (секретный ключ, если требуется)

## Шаг 3: Настройка переменных окружения

Добавьте в файл `.env` в корне проекта:

```env
# Telegram Gateway API Key (получен из личного кабинета)
TELEGRAM_GATEWAY_API_KEY=ваш_api_ключ

# Telegram Gateway API Secret (если требуется)
TELEGRAM_GATEWAY_API_SECRET=ваш_секретный_ключ
```

## Шаг 4: Перезапуск приложения

После добавления переменных окружения:

```bash
# Остановите сервер (Ctrl+C)
# Затем запустите снова
npm run dev
```

## Как это работает?

1. **Пользователь вводит номер телефона** на странице входа (формат: +79001234567)
2. **Нажимает "Получить код"** - сервер:
   - Генерирует 6-значный код
   - Сохраняет его в памяти (с привязкой к номеру телефона)
   - Отправляет запрос в Telegram Gateway API
3. **Telegram Gateway отправляет код** пользователю через официальный канал Telegram
4. **Пользователь получает SMS/сообщение** от официального канала Telegram
5. **Вводит код на сайте** - сервер:
   - Проверяет код
   - Проверяет срок действия (10 минут)
   - Создает или обновляет пользователя в системе
   - Авторизует пользователя

## Стоимость

- **~$0.01 (1-2 рубля)** за каждое успешно доставленное сообщение
- Оплата только за доставленные сообщения
- Минимальный баланс обычно $10-20 для начала работы

## Проверка баланса

Вы можете проверить баланс через API (если поддерживается):

```bash
GET https://api.telegram.org/gateway/balance
Authorization: Bearer YOUR_API_KEY
```

## Безопасность

- Коды действительны только 10 минут
- Каждый код можно использовать только один раз
- Коды автоматически удаляются после использования или истечения срока
- Номер телефона используется для идентификации пользователя

## Формат номера телефона

Номер телефона должен быть в международном формате:
- ✅ `+79001234567` (Россия)
- ✅ `+380501234567` (Украина)
- ✅ `+1234567890` (США)
- ❌ `89001234567` (без +)
- ❌ `8 (900) 123-45-67` (с форматированием)

## Часто задаваемые вопросы

### Нужно ли создавать своего бота?

**Нет!** Telegram Gateway использует официальный канал Telegram, вам не нужно создавать своего бота.

### Сколько стоит отправка одного кода?

**~$0.01 (1-2 рубля)** за каждое успешно доставленное сообщение.

### Как пополнить баланс?

Через личный кабинет Telegram Gateway:
1. Войдите в личный кабинет
2. Перейдите в раздел "Баланс" или "Пополнение"
3. Выберите способ оплаты (карта, PayPal и т.д.)
4. Введите сумму пополнения

### Что если пользователь не получил код?

1. Проверьте баланс в Telegram Gateway
2. Убедитесь, что номер телефона введен правильно
3. Попросите пользователя проверить спам
4. Можно запросить новый код (старый автоматически станет недействительным)

### Можно ли использовать для других целей кроме авторизации?

Да, Telegram Gateway можно использовать для отправки любых сообщений пользователям, но стоимость будет та же (~$0.01 за сообщение).

### Где хранятся коды авторизации?

В текущей реализации коды хранятся в памяти сервера (Map). Для production рекомендуется использовать:
- **Redis** (для распределенных систем)
- **База данных (PostgreSQL)** с автоматической очисткой истекших кодов
