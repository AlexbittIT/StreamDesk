═══════════════════════════════════════════════════════════════
  ЧТО ТАКОЕ PGADMIN?
═══════════════════════════════════════════════════════════════

pgAdmin - это графическая программа для управления базой данных PostgreSQL.

Она выглядит как обычное окно программы (не командная строка) и позволяет:
  ✓ Создавать базы данных
  ✓ Просматривать таблицы
  ✓ Выполнять SQL запросы
  ✓ Управлять пользователями
  ✓ И многое другое

pgAdmin устанавливается автоматически вместе с PostgreSQL.

═══════════════════════════════════════════════════════════════
  КАК НАЙТИ PGADMIN
═══════════════════════════════════════════════════════════════

1. Откройте меню Пуск Windows
2. Найдите "pgAdmin 4" в списке программ
3. Или ищите в папке: PostgreSQL → pgAdmin 4

Если не нашли - возможно, PostgreSQL установлен без pgAdmin.

═══════════════════════════════════════════════════════════════
  КАК ИСПОЛЬЗОВАТЬ PGADMIN ДЛЯ СОЗДАНИЯ БАЗЫ
═══════════════════════════════════════════════════════════════

ШАГ 1: Откройте pgAdmin 4

ШАГ 2: При первом запуске:
  - Вас попросят задать мастер-пароль для pgAdmin
  - Это пароль ДЛЯ ПРОГРАММЫ, а не для базы данных
  - Можете задать любой или пропустить

ШАГ 3: В левой панели найдите:
  Servers → PostgreSQL 16 (или другая версия)

ШАГ 4: Правой кнопкой мыши на "PostgreSQL 16" → Connect Server
  - Введите пароль, который вы задали при установке PostgreSQL
  - Это пароль для пользователя postgres

ШАГ 5: Создайте базу данных:
  - Правой кнопкой на "Databases" → Create → Database
  - Name: streamdesk
  - Нажмите "Save"

Готово! База данных создана.

═══════════════════════════════════════════════════════════════
  АЛЬТЕРНАТИВА: БЕЗ PGADMIN (через командную строку)
═══════════════════════════════════════════════════════════════

Если не хотите использовать pgAdmin, можно через командную строку:

1. Откройте командную строку (CMD)
2. Выполните:
     psql -U postgres
3. Введите пароль PostgreSQL
4. Выполните:
     CREATE DATABASE streamdesk;
5. Выйдите:
     \q

Готово!

═══════════════════════════════════════════════════════════════
  ЕСЛИ PSQL НЕ РАБОТАЕТ
═══════════════════════════════════════════════════════════════

Команда psql может не работать, если PostgreSQL не добавлен в PATH.

Решение:
  1. Найдите папку PostgreSQL (обычно: C:\Program Files\PostgreSQL\16\bin)
  2. Откройте командную строку в этой папке
  3. Или используйте pgAdmin

═══════════════════════════════════════════════════════════════
  АЛЬТЕРНАТИВА 2: SQL SHELL (PSQL)
═══════════════════════════════════════════════════════════════

При установке PostgreSQL также устанавливается "SQL Shell (psql)".

Как найти:
  1. Меню Пуск → PostgreSQL → SQL Shell (psql)
  2. Откроется окно командной строки

Как использовать:
  1. Нажимайте Enter на все вопросы (или введите свои данные)
  2. Введите пароль PostgreSQL
  3. Вы увидите: postgres=#
  4. Введите: CREATE DATABASE streamdesk;
  5. Нажмите Enter
  6. Введите: \q для выхода

Готово!

═══════════════════════════════════════════════════════════════
  ЧТО ЛЕГЧЕ ИСПОЛЬЗОВАТЬ?
═══════════════════════════════════════════════════════════════

Для новичков: pgAdmin 4 (графический интерфейс)
  → Проще и понятнее
  → Не нужно запоминать команды

Для опытных: psql (командная строка)
  → Быстрее
  → Более гибко

═══════════════════════════════════════════════════════════════
  КРАТКОЕ РЕЗЮМЕ
═══════════════════════════════════════════════════════════════

pgAdmin = графическая программа для PostgreSQL
  → Устанавливается вместе с PostgreSQL
  → Меню Пуск → pgAdmin 4

SQL Shell (psql) = командная строка для PostgreSQL
  → Меню Пуск → PostgreSQL → SQL Shell (psql)

Оба способа позволяют создать базу данных streamdesk!
