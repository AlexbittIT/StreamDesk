========================================
ПОДКЛЮЧЕНИЕ К VMIX ЧЕРЕЗ СЕТЬ
StreamDesk
========================================

Если ваш сайт находится на одном сервере, а компьютер с vMix на другом,
нужно настроить удаленное подключение к vMix API.

========================================
ШАГ 1: Настройка vMix для удаленного доступа
========================================

1. ОТКРОЙТЕ НАСТРОЙКИ VMIX
   - В vMix откройте: Settings → Web Controller
   - Или: Settings → API

2. ВКЛЮЧИТЕ WEB CONTROLLER
   - Установите галочку "Enable Web Controller"
   - Установите галочку "Allow Remote Connections" (Разрешить удаленные подключения)
   - По умолчанию используется порт: 8088

3. ПРОВЕРЬТЕ IP АДРЕС КОМПЬЮТЕРА С VMIX
   - Откройте командную строку на компьютере с vMix
   - Выполните: ipconfig (Windows) или ifconfig (Linux/Mac)
   - Найдите IPv4 адрес в локальной сети (например: 192.168.1.100)
   - Или внешний IP адрес, если компьютеры в разных сетях

4. НАСТРОЙТЕ ФАЙРВОЛ WINDOWS
   - Откройте: Панель управления → Система и безопасность → Брандмауэр Windows
   - Нажмите: "Разрешить взаимодействие с приложением"
   - Найдите vMix в списке или добавьте вручную
   - Разрешите входящие подключения на порт 8088
   - Или создайте правило:
     * Тип: Входящее подключение
     * Протокол: TCP
     * Порт: 8088
     * Действие: Разрешить подключение

========================================
ШАГ 2: Как узнать IP адрес компьютера с vMix
========================================

1. ЕСЛИ КОМПЬЮТЕРЫ В ОДНОЙ СЕТИ (локальная сеть):
   - Откройте командную строку на компьютере с vMix
   - Выполните: ipconfig (Windows) или ifconfig (Linux/Mac)
   - Найдите IPv4 адрес (например: 192.168.1.100)
   - Это локальный IP адрес

2. ЕСЛИ КОМПЬЮТЕРЫ В РАЗНЫХ СЕТЯХ (через интернет):
   - Откройте https://whatismyipaddress.com/ на компьютере с vMix
   - Запишите показанный IP адрес
   - Это внешний IP адрес (IP адрес вашего роутера в интернете)

========================================
ШАГ 3: Подключение
========================================

ВАРИАНТ 1: Локальная сеть (оба компьютера в одной сети)

1. В НАСТРОЙКАХ ПОДКЛЮЧЕНИЯ УКАЖИТЕ:
   - Хост: локальный IP адрес компьютера с vMix (например: 192.168.1.100)
   - Порт: 8088

2. НАЖМИТЕ "ПОДКЛЮЧИТЬСЯ"

ВАРИАНТ 2: Через интернет (разные сети)

1. НА КОМПЬЮТЕРЕ С VMIX:
   - Включите Web Controller в настройках vMix
   - Разрешите удаленные подключения
   - Откройте порт 8088 в файрволе Windows

2. НАСТРОЙТЕ PORT FORWARDING В РОУТЕРЕ:
   - Войдите в панель управления роутером (обычно 192.168.1.1)
   - Найдите раздел "Port Forwarding" или "Виртуальные серверы"
   - Добавьте правило:
     * Внешний порт: 8088
     * Внутренний порт: 8088
     * Внутренний IP: локальный IP компьютера с vMix (например: 192.168.1.100)
     * Протокол: TCP
   - Сохраните настройки

3. В НАСТРОЙКАХ ПОДКЛЮЧЕНИЯ УКАЖИТЕ:
   - Хост: внешний IP адрес (который показал whatismyipaddress.com)
   - Порт: 8088

4. НАЖМИТЕ "ПОДКЛЮЧИТЬСЯ"

⚠️  ВНИМАНИЕ: Открытие порта 8088 в интернет делает vMix доступным без пароля!
   Рекомендуется использовать VPN для безопасности.

ВАРИАНТ 2: VPN (рекомендуется)

1. НАСТРОЙТЕ VPN МЕЖДУ СЕРВЕРАМИ
   - Используйте VPN сервис (WireGuard, OpenVPN, Tailscale)
   - Подключите оба компьютера к одной VPN сети

2. В НАСТРОЙКАХ ПОДКЛЮЧЕНИЯ УКАЖИТЕ:
   - Хост: IP адрес компьютера с vMix в VPN сети
   - Порт: 8088

ВАРИАНТ 3: SSH туннель (безопасно)

1. НА СЕРВЕРЕ С САЙТОМ СОЗДАЙТЕ SSH ТУННЕЛЬ:
   ```bash
   ssh -L 8088:localhost:8088 user@vmix-computer-ip
   ```

2. В НАСТРОЙКАХ ПОДКЛЮЧЕНИЯ УКАЖИТЕ:
   - Хост: localhost (или 127.0.0.1)
   - Порт: 8088

ВАРИАНТ 4: Обратный прокси (для продакшена)

1. НАСТРОЙТЕ NGINX/APACHE КАК ПРОКСИ:
   ```nginx
   location /vmix-api/ {
       proxy_pass http://vmix-computer-ip:8088/;
       proxy_set_header Host $host;
   }
   ```

2. ИСПОЛЬЗУЙТЕ ПРОКСИ В КОДЕ:
   - Измените URL запросов на /vmix-api/

========================================
ШАГ 4: Проверка подключения
========================================

1. ПРОВЕРЬТЕ ДОСТУПНОСТЬ ПОРТА:
   На сервере выполните:
   ```bash
   telnet vmix-computer-ip 8088
   ```
   Или:
   ```bash
   curl http://vmix-computer-ip:8088/api?Function=GetVersion
   ```

2. ЕСЛИ ПОРТ НЕ ДОСТУПЕН:
   - Проверьте файрвол на компьютере с vMix
   - Проверьте настройки роутера (Port Forwarding)
   - Убедитесь, что vMix запущен и Web Controller включен

========================================
ШАГ 5: Безопасность
========================================

⚠️  ВАЖНО: vMix API не имеет встроенной аутентификации!

РЕКОМЕНДАЦИИ:

1. ИСПОЛЬЗУЙТЕ VPN
   - Самый безопасный способ для удаленного доступа
   - Все данные передаются в зашифрованном виде

2. ОГРАНИЧЬТЕ ДОСТУП ПО IP
   - Настройте файрвол на компьютере с vMix
   - Разрешите подключения только с IP адреса вашего сервера

3. ИСПОЛЬЗУЙТЕ ОБРАТНЫЙ ПРОКСИ С АУТЕНТИФИКАЦИЕЙ
   - Настройте NGINX с базовой аутентификацией
   - Или используйте Cloudflare Tunnel

4. НЕ ОТКРЫВАЙТЕ ПОРТ 8088 В ИНТЕРНЕТ БЕЗ ЗАЩИТЫ
   - Это может позволить злоумышленникам управлять вашим vMix

========================================
ШАГ 4: Настройка в StreamDesk
========================================

1. ОТКРОЙТЕ РАСПИСАТЕЛЬ VMIX
   - Перейдите в раздел "Расписатель vMix"

2. ВВЕДИТЕ IP АДРЕС КОМПЬЮТЕРА С VMIX:
   - Хост: просто укажите IP адрес компьютера с vMix
     * Если в одной сети: локальный IP (192.168.x.x)
     * Если через интернет: внешний IP (узнайте на whatismyipaddress.com)
     * Если через VPN: IP в VPN сети
   - Порт: 8088 (стандартный порт vMix)

3. НАЖМИТЕ "ПОДКЛЮЧИТЬСЯ"
   - Если подключение успешно, статус изменится на "Онлайн"
   - Вы увидите список входов и текущий статус

4. СОХРАНЕНИЕ НАСТРОЕК
   - Настройки сохраняются автоматически в localStorage браузера
   - При следующем открытии они будут восстановлены

ПРОСТО ЗАПОМНИТЕ:
- IP адрес = адрес компьютера с vMix
- Если в одной сети = локальный IP (192.168.x.x)
- Если через интернет = внешний IP (узнайте на whatismyipaddress.com)

========================================
РЕШЕНИЕ ПРОБЛЕМ
========================================

❌ "Не удалось подключиться к vMix"
   - Проверьте, что vMix запущен
   - Проверьте, что Web Controller включен в настройках vMix
   - Проверьте IP адрес и порт
   - Проверьте файрвол на компьютере с vMix
   - Проверьте настройки роутера (если подключение через интернет)

❌ "vMix не отвечает"
   - Проверьте сетевое подключение между серверами
   - Проверьте, не блокирует ли файрвол порт 8088
   - Попробуйте подключиться с другого компьютера в той же сети

❌ "Порт занят"
   - Проверьте, не используется ли порт 8088 другим приложением
   - Измените порт в настройках vMix Web Controller

❌ Подключение работает только локально
   - Проверьте настройки Port Forwarding в роутере
   - Убедитесь, что внешний IP адрес правильный
   - Проверьте, не блокирует ли провайдер входящие подключения
