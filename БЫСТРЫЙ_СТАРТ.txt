✅ ПРОБЛЕМА РЕШЕНА! Код обновлён для работы с локальной PostgreSQL.

═══════════════════════════════════════════════════════════════
  ЧТО ДЕЛАТЬ:
═══════════════════════════════════════════════════════════════

ШАГ 1: УСТАНОВИТЬ НОВЫЙ ПАКЕТ
───────────────────────────────────────────────────────────────
   
   Откройте командную строку в папке проекта и выполните:
   
     npm install postgres
   
   Или просто запустите dev.bat - он установит автоматически!

═══════════════════════════════════════════════════════════════

ШАГ 2: ПРОВЕРИТЬ POSTGRESQL
───────────────────────────────────────────────────────────────
   
   1. Нажмите Win+R
   2. Введите: services.msc
   3. Найдите "PostgreSQL" или "postgresql"
   4. Убедитесь, что статус "Выполняется"
   5. Если не запущен - нажмите "Запустить"

═══════════════════════════════════════════════════════════════

ШАГ 3: СОЗДАТЬ БАЗУ ДАННЫХ
───────────────────────────────────────────────────────────────
   
   Откройте pgAdmin или командную строку:
   
     CREATE DATABASE streamdesk;
   
   Или через командную строку:
     psql -U postgres
     CREATE DATABASE streamdesk;
     \q

═══════════════════════════════════════════════════════════════

ШАГ 4: НАСТРОИТЬ .env ФАЙЛ
───────────────────────────────────────────────────────────────
   
   Откройте файл .env в корне проекта.
   
   Должна быть строка:
   
     DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/streamdesk
   
   Замените ВАШ_ПАРОЛЬ на пароль PostgreSQL.
   
   Пример:
     DATABASE_URL=postgresql://postgres:mypassword123@localhost:5432/streamdesk
     PORT=5000
     NODE_ENV=development

═══════════════════════════════════════════════════════════════

ШАГ 5: ПРОВЕРИТЬ ПОДКЛЮЧЕНИЕ (опционально)
───────────────────────────────────────────────────────────────
   
   Запустите: check-db.bat
   
   Это проверит подключение к базе данных.

═══════════════════════════════════════════════════════════════

ШАГ 6: ЗАПУСТИТЬ ПРИЛОЖЕНИЕ
───────────────────────────────────────────────────────────────
   
   Запустите: dev.bat
   
   Всё должно заработать!

  ЕСЛИ ВОЗНИКЛИ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════════

1. PostgreSQL не запущен?
   → services.msc → найдите PostgreSQL → Запустить

2. База данных не создана?
   → CREATE DATABASE streamdesk;

3. Неправильный пароль?
   → Проверьте .env файл

4. Пакет postgres не установлен?
   → npm install postgres
