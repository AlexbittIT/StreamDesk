Проблема решена! Код изменён для работы с локальной PostgreSQL.

═══════════════════════════════════════════════════════════════
  ЧТО НУЖНО СДЕЛАТЬ:
═══════════════════════════════════════════════════════════════

1. УСТАНОВИТЬ НОВЫЙ ПАКЕТ
   ───────────────────────────────────────────────────────────
   
   Откройте командную строку в папке проекта и выполните:
   
     npm install postgres
   
   Или запустите:
   
     npm install
   
   (все зависимости установятся автоматически)

═══════════════════════════════════════════════════════════════

2. УБЕДИТЕСЬ, ЧТО POSTGRESQL ЗАПУЩЕН
   ───────────────────────────────────────────────────────────
   
   - Нажмите Win+R
   - Введите: services.msc
   - Найдите "PostgreSQL" или "postgresql"
   - Убедитесь, что служба "Выполняется"
   - Если не запущена - нажмите "Запустить"

═══════════════════════════════════════════════════════════════

3. СОЗДАЙТЕ БАЗУ ДАННЫХ
   ───────────────────────────────────────────────────────────
   
   Откройте pgAdmin или командную строку:
   
     CREATE DATABASE streamdesk;
   
   Или через командную строку:
     psql -U postgres
     CREATE DATABASE streamdesk;
     \q

═══════════════════════════════════════════════════════════════

4. ПРОВЕРЬТЕ ФАЙЛ .env
   ───────────────────────────────────────────────────────────
   
   Откройте файл .env в корне проекта.
   
   Должна быть строка:
   
     DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/streamdesk
   
   Замените ВАШ_ПАРОЛЬ на пароль, который вы задали при установке PostgreSQL.
   
   Пример:
     DATABASE_URL=postgresql://postgres:mypassword123@localhost:5432/streamdesk
     PORT=5000
     NODE_ENV=development

═══════════════════════════════════════════════════════════════

5. ЗАПУСТИТЕ СЕРВЕР
   ───────────────────────────────────────────────────────────
   
   Запустите dev.bat - теперь всё должно работать!
   
   Если появляется ошибка - проверьте:
   - PostgreSQL запущен
   - База данных streamdesk создана
   - Пароль в .env правильный
   - Порт 5432 доступен

═══════════════════════════════════════════════════════════════

ПОСЛЕ УСТАНОВК ПАКЕТА И НАСТРОЙКИ БД:

1. Запустите: npm install postgres
2. Проверьте PostgreSQL (services.msc)
3. Создайте базу данных streamdesk
4. Настройте .env файл
5. Запустите dev.bat
