  ПАРОЛЬ ПРАВИЛЬНЫЙ, НО НЕ РАБОТАЕТ?
═══════════════════════════════════════════════════════════════

Самые частые причины проблемы:

═══════════════════════════════════════════════════════════════
  1. СПЕЦИАЛЬНЫЕ СИМВОЛЫ В ПАРОЛЕ
═══════════════════════════════════════════════════════════════

Если пароль содержит: @ # $ % & ? = + / : или пробелы

→ Откройте encode-password.html в браузере
→ Введите пароль и получите готовую строку для .env

═══════════════════════════════════════════════════════════════
  2. ЗАПУСТИТЕ ДИАГНОСТИКУ
═══════════════════════════════════════════════════════════════

Запустите: check-db-simple.bat

Он покажет точную ошибку и что нужно исправить.

═══════════════════════════════════════════════════════════════
  3. ПРОВЕРЬТЕ POSTGRESQL
═══════════════════════════════════════════════════════════════

Win+R → services.msc → Найдите PostgreSQL → Запущен?

═══════════════════════════════════════════════════════════════
  4. ПРОВЕРЬТЕ ФОРМАТ .env
═══════════════════════════════════════════════════════════════

ПРАВИЛЬНО:
  DATABASE_URL=postgresql://postgres:password@localhost:5432/streamdesk

НЕПРАВИЛЬНО:
  DATABASE_URL="postgresql://..."     ← Убрать кавычки
  DATABASE_URL = postgresql://...     ← Убрать пробелы

═══════════════════════════════════════════════════════════════
  5. СОЗДАНА ЛИ БАЗА ДАННЫХ
═══════════════════════════════════════════════════════════════

База должна существовать! Создайте через pgAdmin:
  CREATE DATABASE streamdesk;
