# Настройка авторизации через Telegram Gateway

Telegram Gateway - это безопасный способ авторизации через Telegram бота. Пользователь получает код в Telegram и вводит его на сайте.

## Как это работает?

1. Пользователь вводит свой Telegram ID на сайте
2. Нажимает "Получить код в Telegram"
3. Бот отправляет 6-значный код пользователю в Telegram
4. Пользователь вводит код на сайте
5. Система проверяет код и авторизует пользователя

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя для вашего бота (например: "StreamDesk Bot")
   - Введите username для бота (должен заканчиваться на `bot`, например: `streamdesk_bot`)
4. BotFather выдаст вам **Bot Token** (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Настройка переменных окружения

Добавьте в файл `.env` в корне проекта:

```env
# Telegram Bot Token (получен от @BotFather)
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

**Важно**: 
- `TELEGRAM_BOT_TOKEN` используется на сервере для отправки сообщений через Telegram Bot API
- Токен должен храниться в секрете и не попадать в клиентский код

## Шаг 3: Как пользователь получает свой Telegram ID?

Пользователь может узнать свой Telegram ID несколькими способами:

### Способ 1: Через бота @userinfobot
1. Откройте Telegram
2. Найдите бота [@userinfobot](https://t.me/userinfobot)
3. Отправьте команду `/start`
4. Бот вернет ваш Telegram ID (число, например: `123456789`)

### Способ 2: Через вашего бота (можно добавить команду)
Можно добавить команду `/myid` в вашего бота, которая будет возвращать ID пользователя.

## Шаг 4: Перезапуск приложения

После добавления переменных окружения:

```bash
# Остановите сервер (Ctrl+C)
# Затем запустите снова
npm run dev
```

## Безопасность

- Коды авторизации действительны только 10 минут
- Каждый код можно использовать только один раз
- Коды автоматически удаляются после использования или истечения срока
- Telegram ID используется для идентификации пользователя

## Процесс авторизации

1. **Пользователь вводит Telegram ID** на странице входа
2. **Нажимает "Получить код"** - сервер:
   - Генерирует 6-значный код
   - Сохраняет его в памяти (с привязкой к Telegram ID и timestamp)
   - Отправляет код пользователю через Telegram Bot API
3. **Пользователь получает код в Telegram** от вашего бота
4. **Вводит код на сайте** - сервер:
   - Проверяет код
   - Проверяет срок действия (10 минут)
   - Создает или обновляет пользователя в системе
   - Авторизует пользователя

## Дополнительные возможности

### Добавление команды /start в бота

Можно настроить бота так, чтобы он автоматически отправлял код при команде `/start`:

1. Используйте webhook или polling для получения обновлений от Telegram
2. При получении команды `/start` от пользователя:
   - Генерируйте код
   - Отправляйте его пользователю
   - Сохраняйте в базе данных для последующей проверки

### Улучшение UX

Можно улучшить процесс:
- Добавить кнопку "Найти мой Telegram ID" с ссылкой на @userinfobot
- Показывать инструкции прямо на странице входа
- Добавить QR-код для быстрого доступа к боту

## Часто задаваемые вопросы

### Нужно ли платить за Telegram Bot API?

**Нет!** Telegram Bot API полностью бесплатный для базовых функций (отправка сообщений, получение обновлений). Платить нужно только за:
- Telegram Premium API (для больших объемов)
- Telegram Ads API (для рекламы)

Для авторизации через Gateway базового Bot API более чем достаточно.

### Где хранятся коды авторизации?

В текущей реализации коды хранятся в памяти сервера (Map). Для production рекомендуется использовать:
- Redis (для распределенных систем)
- База данных (PostgreSQL) с автоматической очисткой истекших кодов

### Что если пользователь не получил код?

Пользователь может:
1. Запросить новый код (старый автоматически станет недействительным)
2. Проверить, что Telegram ID введен правильно
3. Убедиться, что бот не заблокирован

### Можно ли использовать один бот для нескольких приложений?

Да, один бот может использоваться для нескольких приложений, но рекомендуется использовать отдельные боты для лучшей изоляции и безопасности.
