  ЕСЛИ ПАРОЛЬ ПРАВИЛЬНЫЙ, НО НЕ РАБОТАЕТ
═══════════════════════════════════════════════════════════════

Проблема чаще всего в ОДНОМ из этих пунктов:

═══════════════════════════════════════════════════════════════
  1️⃣  СПЕЦИАЛЬНЫЕ СИМВОЛЫ В ПАРОЛЕ
═══════════════════════════════════════════════════════════════

Если пароль содержит @, #, $, %, &, ?, =, +, /, : или пробелы,
их нужно закодировать!

📌 БЫСТРОЕ РЕШЕНИЕ:
   Откройте файл encode-password.html в браузере
   Введите свой пароль и получите готовую строку!

📌 ВРУЧНУЮ:
   @  →  %40
   #  →  %23
   $  →  %24
   %  →  %25
   &  →  %26
   ?  →  %3F
   =  →  %3D
   +  →  %2B
   /  →  %2F
   :  →  %3A
   пробел  →  %20

   Пример:
   Пароль: My@Pass#123
   В .env: DATABASE_URL=postgresql://postgres:My%40Pass%23123@localhost:5432/streamdesk

═══════════════════════════════════════════════════════════════
  2️⃣  НЕПРАВИЛЬНЫЙ ФОРМАТ В .env ФАЙЛЕ
═══════════════════════════════════════════════════════════════

Проверьте формат в файле .env:

✓ ПРАВИЛЬНО:
  DATABASE_URL=postgresql://postgres:password@localhost:5432/streamdesk

✗ НЕПРАВИЛЬНО:
  DATABASE_URL="postgresql://..."     ← БЕЗ КАВЫЧЕК!
  DATABASE_URL = postgresql://...     ← БЕЗ ПРОБЕЛОВ вокруг =
  DATABASE_URL= postgresql://...      ← БЕЗ ПРОБЕЛОВ после =

═══════════════════════════════════════════════════════════════
  3️⃣  POSTGRESQL НЕ ЗАПУЩЕН
═══════════════════════════════════════════════════════════════

1. Win+R → services.msc
2. Найдите "PostgreSQL"
3. Статус должен быть "Выполняется"
4. Если нет - нажмите "Запустить"

═══════════════════════════════════════════════════════════════
  4️⃣  БАЗА ДАННЫХ НЕ СОЗДАНА
═══════════════════════════════════════════════════════════════

База данных должна существовать!

Создайте:
  1. Откройте pgAdmin
  2. Подключитесь к серверу
  3. Правой кнопкой: Databases → Create → Database
  4. Имя: streamdesk
  5. Save

Или через командную строку:
  psql -U postgres
  CREATE DATABASE streamdesk;
  \q

═══════════════════════════════════════════════════════════════
  5️⃣  ДИАГНОСТИКА
═══════════════════════════════════════════════════════════════

Запустите скрипт для диагностики:

  check-db-simple.bat

Он покажет:
  ✓ Правильность DATABASE_URL
  ✓ Детали ошибки
  ✓ Что именно не работает

═══════════════════════════════════════════════════════════════
  ЧТО ДЕЛАТЬ ПРЯМО СЕЙЧАС
═══════════════════════════════════════════════════════════════

ШАГ 1: Проверьте подключение
  → Запустите: check-db-simple.bat
  → Посмотрите на ошибку

ШАГ 2: Если есть спецсимволы в пароле
  → Откройте: encode-password.html
  → Закодируйте пароль
  → Обновите .env файл

ШАГ 3: Проверьте формат .env
  → Нет кавычек
  → Нет пробелов вокруг =
  → Формат: DATABASE_URL=postgresql://...

ШАГ 4: Убедитесь что PostgreSQL запущен
  → services.msc → PostgreSQL → Запущен

ШАГ 5: Убедитесь что база создана
  → pgAdmin → Create Database → streamdesk

═══════════════════════════════════════════════════════════════

После исправления запустите check-db-simple.bat снова!
