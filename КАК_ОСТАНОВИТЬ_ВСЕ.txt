   КАК ОСТАНОВИТЬ ВСЕ ЗАПУЩЕННЫЕ ПРОЦЕССЫ StreamDesk
═══════════════════════════════════════════════════════════════

Если у вас ошибка "Port 5000 is already in use" или вы хотите
остановить все запущенные процессы, используйте эти скрипты:

═══════════════════════════════════════════════════════════════

🚀 БЫСТРЫЙ СПОСОБ:

1. Запустите файл: ОСТАНОВИТЬ_ВСЕ.bat
   → Остановит все процессы Node.js и освободит порты

2. Если не помогло, запустите: ПРОВЕРИТЬ_ПОРТЫ.bat
   → Покажет, какие порты заняты и какими процессами

═══════════════════════════════════════════════════════════════

📋 ПОДРОБНАЯ ИНСТРУКЦИЯ:

┌─────────────────────────────────────────────────────────────┐
│ 1. ОСТАНОВИТЬ_ВСЕ.bat                                       │
│                                                              │
│    - Останавливает все процессы Node.js                     │
│    - Освобождает порты 5000, 5173, 3000                     │
│    - Показывает, что было остановлено                       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 2. ПРОВЕРИТЬ_ПОРТЫ.bat                                      │
│                                                              │
│    - Показывает, какие порты заняты                         │
│    - Показывает PID процессов                                │
│    - Показывает все запущенные Node.js процессы             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 3. УБИТЬ_ПРОЦЕСС.bat [PID]                                  │
│                                                              │
│    - Останавливает конкретный процесс по PID                │
│    - Использование: УБИТЬ_ПРОЦЕСС.bat 12345                 │
│    - PID можно найти через ПРОВЕРИТЬ_ПОРТЫ.bat              │
└─────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════

⚙️ РУЧНОЙ СПОСОБ (если скрипты не работают):

1. Откройте Диспетчер задач (Ctrl+Shift+Esc)

2. Перейдите на вкладку "Процессы" или "Подробности"

3. Найдите процессы:
   - node.exe
   - tsx.exe
   - Любые процессы, использующие порт 5000

4. Нажмите правой кнопкой → "Завершить задачу"

═══════════════════════════════════════════════════════════════

🔍 ПРОВЕРКА ЧЕРЕЗ КОМАНДНУЮ СТРОКУ:

1. Откройте командную строку (cmd) или PowerShell

2. Проверьте порт 5000:
   netstat -ano | findstr ":5000"

3. Увидите что-то вроде:
   TCP    0.0.0.0:5000    0.0.0.0:0    LISTENING    12345
   
   Где 12345 - это PID процесса

4. Остановите процесс:
   taskkill /F /PID 12345

═══════════════════════════════════════════════════════════════

✅ ПОСЛЕ ОСТАНОВКИ:

1. Подождите 2-3 секунды

2. Запустите dev.bat снова

3. Если порт всё ещё занят, измените PORT в .env на другой:
   PORT=5001

═══════════════════════════════════════════════════════════════

💡 СОВЕТЫ:

- Всегда используйте ОСТАНОВИТЬ_ВСЕ.bat перед новым запуском
- Если процессы не останавливаются, перезагрузите компьютер
- Проверяйте порты перед запуском через ПРОВЕРИТЬ_ПОРТЫ.bat
