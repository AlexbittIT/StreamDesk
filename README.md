# StreamDesk - Запуск локального сервера

## 🚀 Быстрый старт (Windows)

### Первый запуск:

1. **Запустите `setup.bat`** - автоматически установит все зависимости и создаст файлы конфигурации
2. **Откройте `.env` файл** и укажите данные вашей PostgreSQL базы данных
3. **Запустите `dev.bat`** - сервер запустится автоматически

### Последующие запуски:

Просто запустите **`dev.bat`** - всё будет готово!

---

## Требования

- Node.js (версия 18 или выше) - [Скачать](https://nodejs.org/)
- PostgreSQL база данных
- npm (устанавливается вместе с Node.js)

## Подробная инструкция

### Шаг 1: Первоначальная настройка

Запустите файл `setup.bat` - он автоматически:
- Проверит наличие Node.js
- Установит все зависимости
- Создаст файл `.env` с настройками по умолчанию

### Шаг 2: Настройка базы данных

1. Убедитесь, что PostgreSQL установлен и запущен
2. Создайте базу данных (например, `streamdesk`)
3. Откройте файл `.env` и измените строку:
   ```
   DATABASE_URL=postgresql://username:password@localhost:5432/database_name
   ```
   
   Замените:
   - `username` - ваш пользователь PostgreSQL (обычно `postgres`)
   - `password` - ваш пароль PostgreSQL
   - `database_name` - название созданной базы данных (например, `streamdesk`)

### Шаг 3: Запуск

Запустите `dev.bat` - сервер автоматически:
- Проверит все зависимости
- Запустит на порту 5000
- Создаст тестовые данные в базе

Приложение будет доступно по адресу: **http://localhost:5000**

**Учетные данные по умолчанию:**
- Логин: `admin`
- Пароль: `admin123`

## Запуск на Windows

### Вариант 1: Использование PowerShell

Откройте PowerShell в корне проекта и выполните:

```powershell
$env:NODE_ENV="development"; npm run dev
```

### Вариант 2: Использование командной строки (CMD)

```cmd
set NODE_ENV=development && npm run dev
```

### Вариант 3: Создание скрипта для Windows

Создайте файл `dev.bat` в корне проекта:

```batch
@echo off
set NODE_ENV=development
npm run dev
```

Затем просто запустите:
```bash
dev.bat
```

### Вариант 4: Использование cross-env (рекомендуется)

Установите `cross-env` для кроссплатформенной поддержки:

```bash
npm install --save-dev cross-env
```

Затем обновите `package.json`:

```json
"dev": "cross-env NODE_ENV=development tsx server/index.ts"
```

И запустите:

```bash
npm run dev
```

## Запуск приложения

После выполнения одной из команд выше:

1. Приложение будет доступно по адресу: `http://localhost:5000`
2. В режиме разработки база данных автоматически заполнится тестовыми данными
3. Стандартные учетные данные для входа:
   - Логин: `admin`
   - Пароль: `admin123`

## Доступные команды

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка для продакшена
- `npm start` - запуск продакшен версии
- `npm run check` - проверка TypeScript типов
- `npm run db:push` - применение изменений схемы базы данных

## Проблемы при запуске

### Ошибка подключения к базе данных

Убедитесь, что:
- PostgreSQL запущен
- DATABASE_URL в `.env` файле правильный
- База данных существует

### Порт уже занят

Измените PORT в `.env` файле или остановите процесс, использующий порт 5000.

### Ошибки с зависимостями

Попробуйте:
```bash
rm -rf node_modules package-lock.json
npm install
```
