# Настройка Telegram авторизации

## Описание
StreamDesk поддерживает авторизацию через Telegram Login Widget. Пользователи могут войти в систему, нажав на кнопку Telegram и подтвердив доступ в своем Telegram-приложении.

## Настройка

### 1. Создание Telegram бота

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните **Bot Token** (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Настройка домена

1. Отправьте команду `/setdomain` боту BotFather
2. Выберите вашего бота
3. Укажите домен вашего приложения (например: `yourdomain.com` или `localhost:8455` для разработки)

**Важно:** Для локальной разработки можно использовать `localhost`, но для продакшена нужен реальный домен с HTTPS.

### 3. Настройка переменных окружения

Добавьте в файл `.env` (или `.env.local`):

```env
# Telegram Bot Token (получен от @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token_here

# Telegram Bot Username (без @, например: my_streamdesk_bot)
VITE_TELEGRAM_BOT_USERNAME=your_bot_username_here
```

### 4. Перезапуск приложения

После настройки переменных окружения перезапустите сервер и клиент:

```bash
# Остановите текущие процессы (Ctrl+C)
# Затем запустите снова
npm run dev
```

## Как это работает

1. Пользователь нажимает на кнопку Telegram Login Widget на странице входа
2. Открывается окно Telegram с запросом на авторизацию
3. Пользователь подтверждает доступ в Telegram
4. Telegram отправляет данные пользователя обратно в приложение
5. Приложение создает или обновляет пользователя в базе данных
6. Пользователь автоматически входит в систему

## Безопасность

- Telegram Login Widget использует криптографическую подпись для проверки данных
- Сервер проверяет подпись с помощью `TELEGRAM_BOT_TOKEN`
- Данные пользователя передаются безопасно через HTTPS

## Отладка

Если авторизация не работает:

1. Проверьте, что `TELEGRAM_BOT_TOKEN` и `VITE_TELEGRAM_BOT_USERNAME` установлены правильно
2. Убедитесь, что домен настроен в BotFather
3. Проверьте консоль браузера на наличие ошибок
4. Проверьте логи сервера

## Демо-режим

Если `VITE_TELEGRAM_BOT_USERNAME` не установлен, будет показана кнопка "Войти через Telegram (демо)", которая создает тестового пользователя без реальной авторизации через Telegram.
