========================================
НАСТРОЙКА ДОСТУПА ПО ДОМЕНУ
StreamDesk
========================================

Для доступа к вашему приложению по купленному домену выполните следующие шаги:

========================================
ВАРИАНТ 1: Настройка через роутер (рекомендуется)
========================================

1. УЗНАЙТЕ ВАШ ВНЕШНИЙ IP АДРЕС
   - Откройте https://whatismyipaddress.com/
   - Запишите ваш внешний IP адрес

2. НАСТРОЙТЕ PORT FORWARDING В РОУТЕРЕ
   - Войдите в панель управления роутером (обычно 192.168.1.1 или 192.168.0.1)
   - Найдите раздел "Port Forwarding" или "Виртуальные серверы"
   - Добавьте правило:
     * Внешний порт: 5000 (или 80 для HTTP, 443 для HTTPS)
     * Внутренний порт: 5000
     * Внутренний IP: IP адрес вашего ноутбука в локальной сети
     * Протокол: TCP
   - Сохраните настройки

3. НАСТРОЙТЕ DNS ЗАПИСИ У РЕГИСТРАТОРА ДОМЕНА
   - Войдите в панель управления вашего регистратора домена
   - Найдите раздел "DNS управление" или "DNS записи"
   - Добавьте A-запись:
     * Имя: @ (или www для поддомена)
     * Тип: A
     * Значение: ваш внешний IP адрес (из шага 1)
     * TTL: 3600 (или по умолчанию)
   - Сохраните изменения
   - Подождите 5-30 минут для распространения DNS

4. ПРОВЕРЬТЕ ДОСТУП
   - Откройте браузер
   - Перейдите по адресу: http://ваш-домен.com:5000
   - Если настроили порт 80: http://ваш-домен.com
   - Если настроили порт 443: https://ваш-домен.com

========================================
ВАРИАНТ 2: Использование ngrok (быстрый способ)
========================================

1. УСТАНОВИТЕ NGROK
   - Скачайте с https://ngrok.com/download
   - Распакуйте в папку (например, C:\ngrok)
   - Зарегистрируйтесь на ngrok.com и получите токен

2. НАСТРОЙТЕ NGROK
   - Откройте командную строку
   - Выполните: ngrok config add-authtoken ВАШ_ТОКЕН

3. ЗАПУСТИТЕ NGROK
   - В отдельном окне терминала выполните:
     ngrok http 5000
   - Скопируйте URL (например: https://abc123.ngrok.io)

4. НАСТРОЙТЕ CUSTOM DOMAIN (опционально)
   - В панели ngrok добавьте ваш домен
   - Выполните: ngrok http 5000 --domain=ваш-домен.com

========================================
ВАРИАНТ 3: Использование Cloudflare Tunnel (бесплатно)
========================================

1. УСТАНОВИТЕ CLOUDFLARE TUNNEL
   - Скачайте cloudflared с https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/
   - Зарегистрируйтесь на Cloudflare.com

2. СОЗДАЙТЕ ТУННЕЛЬ
   - Выполните: cloudflared tunnel create streamdesk
   - Выполните: cloudflared tunnel route dns streamdesk ваш-домен.com

3. ЗАПУСТИТЕ ТУННЕЛЬ
   - Создайте файл config.yml:
     tunnel: streamdesk
     credentials-file: C:\Users\ВашеИмя\.cloudflared\streamdesk.json
     ingress:
       - hostname: ваш-домен.com
         service: http://localhost:5000
       - service: http_status:404
   - Выполните: cloudflared tunnel run streamdesk

========================================
ВАЖНЫЕ ЗАМЕЧАНИЯ
========================================

⚠️  БЕЗОПАСНОСТЬ:
   - Используйте HTTPS для продакшена
   - Настройте SSL сертификат (Let's Encrypt бесплатно)
   - Используйте сильные пароли
   - Настройте файрвол

⚠️  ПРОИЗВОДИТЕЛЬНОСТЬ:
   - Для продакшена используйте сборку: npm run build
   - Запускайте через: npm start
   - Рассмотрите использование PM2 для автозапуска

⚠️  ПОРТЫ:
   - По умолчанию используется порт 5000
   - Для HTTP используйте порт 80
   - Для HTTPS используйте порт 443
   - Измените PORT в .env файле при необходимости

========================================
ПРОВЕРКА НАСТРОЙКИ
========================================

1. Проверьте, что сервер запущен:
   - Откройте http://localhost:5000
   - Должна открыться страница входа

2. Проверьте доступ извне:
   - Используйте мобильный интернет (не Wi-Fi)
   - Откройте http://ваш-внешний-ip:5000
   - Должна открыться страница входа

3. Проверьте DNS:
   - Выполните: nslookup ваш-домен.com
   - Должен вернуться ваш внешний IP

========================================
РЕШЕНИЕ ПРОБЛЕМ
========================================

❌ Не могу подключиться извне:
   - Проверьте настройки файрвола Windows
   - Проверьте Port Forwarding в роутере
   - Убедитесь, что сервер запущен

❌ DNS не работает:
   - Подождите до 30 минут для распространения
   - Проверьте правильность A-записи
   - Используйте онлайн сервисы для проверки DNS

❌ Порт занят:
   - Измените PORT в .env файле
   - Или остановите процесс, использующий порт 5000

========================================
ПОДДЕРЖКА
========================================

Если возникли проблемы:
1. Проверьте логи сервера
2. Проверьте настройки .env файла
3. Убедитесь, что PostgreSQL запущен
4. Проверьте подключение к интернету
