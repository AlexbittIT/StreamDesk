📋 БЫСТРЫЙ СТАРТ:

1️⃣  Первый раз? Запустите:  setup.bat
    (установит зависимости и создаст файлы настроек)

2️⃣  Откройте файл:  .env
    Укажите данные для подключения к PostgreSQL

3️⃣  Запустите:  dev.bat
    (сервер запустится автоматически)

4️⃣  Откройте в браузере:  http://localhost:5000

5️⃣  Войдите:
    Логин:  admin
    Пароль: admin123

═══════════════════════════════════════════════════════════════

📝 ПОДРОБНАЯ ИНСТРУКЦИЯ:

ШАГ 1: Настройка базы данных PostgreSQL
   - Установите PostgreSQL (если еще не установлен)
   - Запустите PostgreSQL
   - Создайте базу данных: CREATE DATABASE streamdesk;

ШАГ 2: Настройка файла .env
   Откройте файл .env и измените:
   DATABASE_URL=postgresql://ваш_логин:ваш_пароль@localhost:5432/streamdesk

   Пример:
   DATABASE_URL=postgresql://postgres:mypassword@localhost:5432/streamdesk

ШАГ 3: Запуск
   - Первый раз: запустите setup.bat
   - Далее: просто запускайте dev.bat

═══════════════════════════════════════════════════════════════

❓ ПРОБЛЕМЫ?

1. Ошибка подключения к базе данных
   → Проверьте, что PostgreSQL запущен
   → Проверьте данные в .env файле
   → Убедитесь, что база данных создана

2. Порт 5000 занят
   → Измените PORT в .env файле на другой (например, 5001)

3. Node.js не найден
   → Установите Node.js с https://nodejs.org/
