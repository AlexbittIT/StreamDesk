═══════════════════════════════════════════════════════════════
  КАК СКАЧАТЬ И УСТАНОВИТЬ POSTGRESQL НА WINDOWS
═══════════════════════════════════════════════════════════════

ШАГ 1: СКАЧАТЬ POSTGRESQL
───────────────────────────────────────────────────────────────

1. Откройте официальный сайт PostgreSQL:
   https://www.postgresql.org/download/windows/

2. Или сразу скачайте установщик:
   https://www.postgresql.org/download/windows/installer/

3. Выберите версию (рекомендуется последняя стабильная):
   - Нажмите на "Download the installer"
   - Выберите версию (например, PostgreSQL 16.x)
   - Выберите ваш вариант Windows (32-bit или 64-bit)

4. Скачайте установщик (файл .exe, примерно 200-300 МБ)

═══════════════════════════════════════════════════════════════

ШАГ 2: УСТАНОВИТЬ POSTGRESQL
───────────────────────────────────────────────────────────────

1. Запустите скачанный файл установки

2. Следуйте инструкциям установщика:
   - Нажмите "Next"
   - Выберите папку установки (по умолчанию C:\Program Files\PostgreSQL\16)
   - Выберите компоненты (оставьте все по умолчанию)
   - Нажмите "Next"

3. ВАЖНО: Запомните или запишите пароль для пользователя postgres!
   - Установщик попросит создать пароль для суперпользователя
   - Введите надежный пароль (запомните его!)
   - Это будет пароль для подключения к базе данных

4. Выберите порт (по умолчанию 5432) - оставьте как есть

5. Выберите локаль (Locale) - обычно "Russian, Russia" или "Default"

6. Завершите установку - нажмите "Finish"

═══════════════════════════════════════════════════════════════

ШАГ 3: ПРОВЕРИТЬ УСТАНОВКУ
───────────────────────────────────────────────────────────────

1. Нажмите Win+R
2. Введите: services.msc
3. Найдите в списке "postgresql-x64-16" (или похожее)
4. Убедитесь, что статус "Выполняется"

Если служба не запущена:
  - Правой кнопкой мыши → "Запустить"

═══════════════════════════════════════════════════════════════

ШАГ 4: НАСТРОИТЬ БАЗУ ДАННЫХ ДЛЯ STREAMDESK
───────────────────────────────────────────────────────────────

1. Откройте "pgAdmin 4" (должно появиться после установки)
   Или найдите в меню Пуск: PostgreSQL → pgAdmin 4

2. При первом запуске:
   - Вас попросят задать мастер-пароль для pgAdmin
   - Это отдельный пароль для программы (не для БД)

3. В левой панели найдите:
   Servers → PostgreSQL 16 → правой кнопкой → Connect Server

4. Введите пароль суперпользователя (тот, что вы задали при установке)

5. Создайте базу данных:
   - Правой кнопкой на "Databases" → Create → Database
   - Name: streamdesk
   - Нажмите "Save"

═══════════════════════════════════════════════════════════════

ШАГ 5: НАСТРОИТЬ ФАЙЛ .env
───────────────────────────────────────────────────────────────

Откройте файл .env в папке проекта StreamDesk и укажите:

  DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/streamdesk

Замените ВАШ_ПАРОЛЬ на пароль, который вы задали при установке PostgreSQL.

Пример:
  DATABASE_URL=postgresql://postgres:MyPassword123@localhost:5432/streamdesk
  PORT=5000
  NODE_ENV=development

═══════════════════════════════════════════════════════════════

АЛЬТЕРНАТИВА: ЧЕРЕЗ КОМАНДНУЮ СТРОКУ
───────────────────────────────────────────────────────────────

Если вы предпочитаете командную строку:

1. Откройте командную строку (CMD) или PowerShell

2. Перейдите в папку PostgreSQL (или используйте полный путь):
   cd "C:\Program Files\PostgreSQL\16\bin"

3. Создайте базу данных:
   psql -U postgres
   
   (Введите пароль при запросе)

4. В psql выполните:
   CREATE DATABASE streamdesk;
   \q

═══════════════════════════════════════════════════════════════

ПРОВЕРКА ПОДКЛЮЧЕНИЯ
───────────────────────────────────────────────────────────────

После настройки:

1. Убедитесь, что PostgreSQL запущен (services.msc)
2. Проверьте файл .env (правильный DATABASE_URL)
3. Запустите dev.bat
4. Если всё правильно - сервер запустится без ошибок БД

═══════════════════════════════════════════════════════════════

ЕСЛИ ВОЗНИКЛИ ПРОБЛЕМЫ
───────────────────────────────────────────────────────────────

1. Забыли пароль postgres?
   - Откройте файл: C:\Program Files\PostgreSQL\16\data\pg_hba.conf
   - Найдите строку: host all all 127.0.0.1/32 md5
   - Измените md5 на trust
   - Перезапустите службу PostgreSQL
   - Подключитесь без пароля и задайте новый:
     ALTER USER postgres WITH PASSWORD 'новый_пароль';

2. Порт 5432 занят?
   - Измените порт при установке или в настройках

3. Файрвол блокирует?
   - Добавьте PostgreSQL в исключения файрвола Windows
