  ПОШАГОВАЯ ДИАГНОСТИКА ПРОБЛЕМЫ С БД
═══════════════════════════════════════════════════════════════

Если пароль правильный, но подключение не работает, следуйте этим шагам:

═══════════════════════════════════════════════════════════════
  ШАГ 1: ЗАПУСТИТЕ ДИАГНОСТИКУ
═══════════════════════════════════════════════════════════════

Запустите файл: check-db-simple.bat

Он покажет точную ошибку и что нужно исправить.

═══════════════════════════════════════════════════════════════
  ШАГ 2: ПРОВЕРЬТЕ POSTGRESQL
═══════════════════════════════════════════════════════════════

1. Нажмите Win+R
2. Введите: services.msc
3. Найдите службу "PostgreSQL" (может называться "postgresql-x64-16")
4. Проверьте статус - должно быть "Выполняется"
5. Если не запущен - нажмите правой кнопкой → "Запустить"

═══════════════════════════════════════════════════════════════
  ШАГ 3: ПРОВЕРЬТЕ ФОРМАТ .env ФАЙЛА
═══════════════════════════════════════════════════════════════

Откройте файл .env и проверьте строку DATABASE_URL:

ПРАВИЛЬНЫЙ ФОРМАТ:
  DATABASE_URL=postgresql://postgres:password@localhost:5432/streamdesk

ЧАСТЫЕ ОШИБКИ:
  ✗ DATABASE_URL="postgresql://..."     ← Уберите кавычки!
  ✗ DATABASE_URL = postgresql://...     ← Уберите пробелы вокруг =
  ✗ DATABASE_URL=postgresql://...       ← Нет пробела после =

═══════════════════════════════════════════════════════════════
  ШАГ 4: ПРОВЕРЬТЕ СПЕЦИАЛЬНЫЕ СИМВОЛЫ В ПАРОЛЕ
═══════════════════════════════════════════════════════════════

Если в пароле есть символы: @ # $ % & ? = + / : или пробелы,
их нужно закодировать!

БЫСТРОЕ РЕШЕНИЕ:
  → Откройте файл encode-password.html в браузере
  → Введите свой пароль
  → Скопируйте готовую строку для .env

ВРУЧНУЮ:
  @ → %40    # → %23    $ → %24    % → %25
  & → %26    ? → %3F    = → %3D    + → %2B
  / → %2F    : → %3A    пробел → %20

═══════════════════════════════════════════════════════════════
  ШАГ 5: ПРОВЕРЬТЕ, ЧТО БАЗА ДАННЫХ СОЗДАНА
═══════════════════════════════════════════════════════════════

База данных должна существовать до подключения!

Создать базу:

ЧЕРЕЗ pgAdmin:
  1. Откройте pgAdmin
  2. Подключитесь к серверу (введите пароль)
  3. Правой кнопкой на "Databases" → Create → Database
  4. Name: streamdesk
  5. Save

ЧЕРЕЗ КОМАНДНУЮ СТРОКУ:
  1. Откройте командную строку
  2. Выполните: psql -U postgres
  3. Введите пароль
  4. Выполните: CREATE DATABASE streamdesk;
  5. Выполните: \q

═══════════════════════════════════════════════════════════════
  ШАГ 6: ПРОВЕРЬТЕ ПАРОЛЬ В ПРЯМОМ ПОДКЛЮЧЕНИИ
═══════════════════════════════════════════════════════════════

Попробуйте подключиться напрямую через psql:

  1. Откройте командную строку
  2. Выполните: psql -U postgres -h localhost -p 5432
  3. Введите пароль
  4. Если подключается - пароль правильный

Если не подключается - проблема в пароле, проверьте его.

═══════════════════════════════════════════════════════════════
  ШАГ 7: ПРОВЕРЬТЕ ПОРТ
═══════════════════════════════════════════════════════════════

По умолчанию PostgreSQL использует порт 5432.

Если ваш PostgreSQL на другом порту:

  1. Откройте pgAdmin
  2. Правой кнопкой на сервере → Properties
  3. Вкладка "Connection" → посмотрите "Port"
  4. Обновите .env файл:
     DATABASE_URL=postgresql://postgres:password@localhost:ВАШ_ПОРТ/streamdesk

═══════════════════════════════════════════════════════════════
  ЧТО ДЕЛАТЬ ПОСЛЕ ИСПРАВЛЕНИЙ
═══════════════════════════════════════════════════════════════

1. Исправьте проблему согласно шагам выше
2. Запустите check-db-simple.bat снова
3. Если показывает "✅ ПОДКЛЮЧЕНИЕ УСПЕШНО!" - всё готово!
4. Запустите dev.bat - приложение должно работать

═══════════════════════════════════════════════════════════════
  ЕСЛИ НИЧЕГО НЕ ПОМОГЛО
═══════════════════════════════════════════════════════════════

1. Запустите check-db-simple.bat
2. Скопируйте полный текст ошибки
3. Проверьте файл ЧТО_ДЕЛАТЬ_ЕСЛИ_НЕ_РАБОТАЕТ.txt
4. Посмотрите на детали ошибки - там будет подсказка
