  КАК СОЗДАТЬ БАЗУ ДАННЫХ STREAMDESK - 3 СПОСОБА
═══════════════════════════════════════════════════════════════

Вам нужно создать базу данных с именем "streamdesk".

Выберите любой удобный способ:

═══════════════════════════════════════════════════════════════
  СПОСОБ 1: PGADMIN (САМЫЙ ПРОСТОЙ)
═══════════════════════════════════════════════════════════════

1. Откройте меню Пуск
2. Найдите "pgAdmin 4" и запустите
3. При первом запуске задайте мастер-пароль (можно любой)
4. В левой панели найдите: Servers → PostgreSQL
5. Правой кнопкой на "PostgreSQL" → Connect Server
6. Введите пароль PostgreSQL (который задали при установке)
7. Правой кнопкой на "Databases" → Create → Database
8. Name: streamdesk
9. Нажмите "Save"

Готово! ✅

═══════════════════════════════════════════════════════════════
  СПОСОБ 2: SQL SHELL (PSQL) - ИЗ МЕНЮ ПУСК
═══════════════════════════════════════════════════════════════

1. Откройте меню Пуск
2. Найдите "PostgreSQL" → "SQL Shell (psql)"
3. Откроется окно командной строки
4. Нажимайте Enter на все вопросы (или введите свои данные):
   - Server: [localhost] → Enter
   - Database: [postgres] → Enter
   - Port: [5432] → Enter
   - Username: [postgres] → Enter
   - Password: введите пароль PostgreSQL → Enter
5. Появится: postgres=#
6. Введите: CREATE DATABASE streamdesk;
7. Нажмите Enter
8. Должно появиться: CREATE DATABASE
9. Введите: \q
10. Нажмите Enter

Готово! ✅

═══════════════════════════════════════════════════════════════
  СПОСОБ 3: КОМАНДНАЯ СТРОКА (CMD)
═══════════════════════════════════════════════════════════════

1. Откройте командную строку (Win+R → cmd)
2. Найдите папку PostgreSQL:
     cd "C:\Program Files\PostgreSQL\16\bin"
   
   (Если версия другая, замените 16 на вашу версию)

3. Выполните:
     psql -U postgres

4. Введите пароль PostgreSQL
5. Введите: CREATE DATABASE streamdesk;
6. Нажмите Enter
7. Введите: \q
8. Нажмите Enter

Готово! ✅

  ПРОВЕРКА: БАЗА СОЗДАНА?
═══════════════════════════════════════════════════════════════

После создания базы, проверьте через pgAdmin:
  → Databases → должна появиться "streamdesk"

Или через SQL Shell:
  → \l  (показывает список всех баз данных)
