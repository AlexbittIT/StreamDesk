# Настройка авторизации через Telegram

Авторизация через Telegram **полностью бесплатна**! Вам не нужно платить деньги за использование Telegram Login Widget.

## Что такое Telegram Login Widget?

Telegram Login Widget - это официальный бесплатный способ авторизации пользователей через Telegram. Он позволяет пользователям войти в ваше приложение одним кликом, используя свой Telegram аккаунт.

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя для вашего бота (например: "StreamDesk Bot")
   - Введите username для бота (должен заканчиваться на `bot`, например: `streamdesk_bot`)
4. BotFather выдаст вам **Bot Token** (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Настройка домена для Login Widget

1. Отправьте BotFather команду `/newapp`
2. Выберите вашего бота из списка
3. Введите название приложения (например: "StreamDesk")
4. Введите короткое описание (например: "CRM система для управления стримами")
5. **Важно**: Введите домен вашего сайта (например: `streamdesk.ru`)
6. Опционально: загрузите иконку приложения

## Шаг 3: Настройка переменных окружения

Добавьте в файл `.env` в корне проекта (создайте его, если его нет):

```env
# Telegram Bot Token (получен от @BotFather)
# Пример: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_BOT_TOKEN=ваш_токен_бота

# Telegram Bot Username (например: streamdesk_bot)
# БЕЗ символа @ в начале!
VITE_TELEGRAM_BOT_USERNAME=ваш_username_бота
```

**Важно**: 
- `TELEGRAM_BOT_TOKEN` используется на сервере для проверки безопасности (хранится в `.env`, не попадает в клиент)
- `VITE_TELEGRAM_BOT_USERNAME` используется на клиенте для отображения виджета (начинается с `VITE_` чтобы быть доступным в браузере)
- **НЕ добавляйте символ @ перед username!** Используйте просто `streamdesk_bot`, а не `@streamdesk_bot`

## Шаг 4: Перезапуск приложения

После добавления переменных окружения:

```bash
# Остановите сервер (Ctrl+C)
# Затем запустите снова
npm run dev
```

## Как это работает?

1. Пользователь нажимает кнопку "Войти через Telegram" на странице входа
2. Telegram открывает окно авторизации (если виджет настроен) или используется демо-режим
3. Пользователь подтверждает вход
4. Telegram возвращает данные пользователя (ID, имя, фото, hash и т.д.)
5. **Сервер проверяет подлинность данных через Bot Token** - вычисляет hash и сравнивает с полученным
6. Если проверка успешна, создается или обновляется аккаунт пользователя в системе
7. Пользователь автоматически входит в систему

**Безопасность**: Все данные от Telegram подписываются криптографическим hash, который невозможно подделать без знания Bot Token.

## Безопасность

- Telegram Login Widget использует криптографическую подпись (hash) для проверки подлинности
- Сервер проверяет hash используя Bot Token
- Данные не могут быть подделаны без знания Bot Token

## Часто задаваемые вопросы

### Нужно ли платить за Telegram Login Widget?

**Нет!** Telegram Login Widget полностью бесплатный. Вам не нужно платить деньги или пополнять баланс.

### Что если у меня нет домена?

Для локальной разработки можно использовать:
- `localhost` (но виджет может не работать)
- Или использовать демо-режим (кнопка "Войти через Telegram" без виджета)

### Где взять Bot Token?

Bot Token выдает [@BotFather](https://t.me/BotFather) при создании бота. Он выглядит как:
```
123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

### Можно ли использовать один бот для нескольких доменов?

Да, можно настроить несколько доменов через BotFather командой `/newapp` для одного бота.

### Что делать если виджет не отображается?

1. Проверьте, что `VITE_TELEGRAM_BOT_USERNAME` правильно указан в `.env`
2. Убедитесь, что домен настроен в BotFather
3. Проверьте консоль браузера на наличие ошибок
4. Убедитесь, что сайт открыт по HTTPS (для production)
