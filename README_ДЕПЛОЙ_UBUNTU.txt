═══════════════════════════════════════════════════════════════
  БЫСТРЫЙ СТАРТ:
═══════════════════════════════════════════════════════════════

1. Подключитесь к серверу: ssh username@server-ip

2. Установите ПО (выберите один вариант):
   
   Вариант A: Автоматически
   sudo bash setup-ubuntu-server.sh
   
   Вариант B: Вручную
   Следуйте инструкциям в ПОЛНАЯ_ИНСТРУКЦИЯ_ДЕПЛОЙ_UBUNTU.md

3. Создайте базу данных:
   sudo -u postgres psql
   CREATE DATABASE streamdesk;
   CREATE USER streamdesk_user WITH PASSWORD 'пароль';
   GRANT ALL PRIVILEGES ON DATABASE streamdesk TO streamdesk_user;
   \q

4. На вашем Windows компьютере:
   - Откройте deploy-to-server.bat
   - Измените настройки (SERVER_USER, SERVER_IP, SERVER_PATH)
   - Сохраните и запустите файл

5. На сервере создайте .env файл:
   cd /var/www/streamdesk
   nano .env
   (см. содержимое в ПОЛНАЯ_ИНСТРУКЦИЯ_ДЕПЛОЙ_UBUNTU.md)

6. Создайте таблицы в БД:
   sudo -u postgres psql -d streamdesk -f create_connection_schemas_tables.sql

7. Настройте Nginx (см. ПОЛНАЯ_ИНСТРУКЦИЯ_ДЕПЛОЙ_UBUNTU.md)

8. Установите SSL:
   sudo certbot --nginx -d ваш-домен.com

9. Настройте DNS записи у регистратора домена

10. Готово! Откройте https://ваш-домен.com

После первоначальной настройки:

Каждый раз, когда обновляете файлы:
→ Запустите deploy-to-server.bat на вашем компьютере
→ Файлы автоматически синхронизируются и приложение перезапустится

Или используйте Git (если настроили):
→ git push origin main
→ Изменения автоматически применятся на сервере
