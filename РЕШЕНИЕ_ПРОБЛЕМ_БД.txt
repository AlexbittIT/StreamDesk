  РЕШЕНИЕ ПРОБЛЕМ С ПОДКЛЮЧЕНИЕМ К БАЗЕ ДАННЫХ
═══════════════════════════════════════════════════════════════

Если у вас правильный пароль, но подключение не работает,
проверьте следующие пункты:

═══════════════════════════════════════════════════════════════
  ПРОБЛЕМА 1: СПЕЦИАЛЬНЫЕ СИМВОЛЫ В ПАРОЛЕ
═══════════════════════════════════════════════════════════════

Если в пароле есть специальные символы (@, #, $, %, & и т.д.),
их нужно закодировать в URL-формате!

Примеры кодирования:
  @  →  %40
  #  →  %23
  $  →  %24
  %  →  %25
  &  →  %26
  ?  →  %3F
  =  →  %3D
  +  →  %2B
  /  →  %2F
  :  →  %3A
  пробел  →  %20

ПРИМЕР:
  Если пароль: My@Pass#123
  То в .env должно быть:
    DATABASE_URL=postgresql://postgres:My%40Pass%23123@localhost:5432/streamdesk

═══════════════════════════════════════════════════════════════
  ПРОБЛЕМА 2: НЕПРАВИЛЬНЫЙ ФОРМАТ DATABASE_URL
═══════════════════════════════════════════════════════════════

Формат должен быть ТОЧНО таким:
  postgresql://username:password@host:port/database

Проверьте:
  ✓ Нет лишних пробелов
  ✓ Нет кавычек вокруг строки
  ✓ Правильный порядок: username:password@host:port/database

ПРАВИЛЬНО:
  DATABASE_URL=postgresql://postgres:mypassword@localhost:5432/streamdesk

НЕПРАВИЛЬНО:
  DATABASE_URL="postgresql://postgres:mypassword@localhost:5432/streamdesk"
  DATABASE_URL = postgresql://postgres:mypassword@localhost:5432/streamdesk
  DATABASE_URL=postgresql://postgres: mypassword @localhost:5432/streamdesk

═══════════════════════════════════════════════════════════════
  ПРОБЛЕМА 3: POSTGRESQL НЕ ЗАПУЩЕН
═══════════════════════════════════════════════════════════════

1. Нажмите Win+R
2. Введите: services.msc
3. Найдите "PostgreSQL" или "postgresql-x64-16"
4. Проверьте статус - должно быть "Выполняется"
5. Если не запущен - нажмите "Запустить"

═══════════════════════════════════════════════════════════════
  ПРОБЛЕМА 4: БАЗА ДАННЫХ НЕ СОЗДАНА
═══════════════════════════════════════════════════════════════

База данных должна существовать перед подключением!

Создайте её:
  1. Откройте pgAdmin
  2. Подключитесь к серверу PostgreSQL
  3. Правой кнопкой на "Databases" → Create → Database
  4. Имя: streamdesk
  5. Save

Или через командную строку:
  psql -U postgres
  CREATE DATABASE streamdesk;
  \q

═══════════════════════════════════════════════════════════════
  ПРОБЛЕМА 5: НЕПРАВИЛЬНЫЙ ПОРТ
═══════════════════════════════════════════════════════════════

По умолчанию PostgreSQL использует порт 5432.

Если ваш PostgreSQL на другом порту, укажите его:
  DATABASE_URL=postgresql://postgres:password@localhost:5433/streamdesk
                                                         ^^^^
                                                         ваш порт

Узнать порт можно:
  - В pgAdmin: правой кнопкой на сервере → Properties → Connection → Port
  - Или: services.msc → PostgreSQL → Properties → Путь к исполняемому файлу

═══════════════════════════════════════════════════════════════
  ДИАГНОСТИКА: ЗАПУСТИТЕ ПРОВЕРКУ
═══════════════════════════════════════════════════════════════

Запустите скрипт диагностики:

  check-db-simple.bat

Он покажет:
  ✓ Правильно ли настроен DATABASE_URL
  ✓ Какие параметры используются
  ✓ Детальную информацию об ошибке

═══════════════════════════════════════════════════════════════
  ЧЕКЛИСТ ДЛЯ ПРОВЕРКИ
═══════════════════════════════════════════════════════════════

[ ] PostgreSQL запущен (services.msc)
[ ] База данных streamdesk создана
[ ] .env файл в корне проекта
[ ] DATABASE_URL в правильном формате
[ ] Специальные символы в пароле закодированы
[ ] Нет пробелов и кавычек в DATABASE_URL
[ ] Правильный порт (обычно 5432)
[ ] Правильный пользователь (обычно postgres)
[ ] Пароль правильный

  БЫСТРОЕ РЕШЕНИЕ

1. Запустите: check-db-simple.bat
2. Посмотрите на ошибку
3. Исправьте проблему согласно описанию выше
4. Запустите проверку снова
