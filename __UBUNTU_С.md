# азвертывание StreamDesk на Ubuntu 24 Server

олная инструкция по развертыванию приложения на Ubuntu сервере.

См. файлы:
- setup-ubuntu-server.sh - автоматическая настройка сервера
- deploy-to-server.sh - скрипт деплоя на сервере  
- deploy-to-server.bat - скрипт деплоя с Windows
- ecosystem.config.js - конфигурация PM2
- nginx-config-example.conf - пример конфигурации Nginx
