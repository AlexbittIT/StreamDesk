Для работы схем подключения нужно создать таблицы в базе данных.

═══════════════════════════════════════════════════════════════
  СПОСОБ 1: ЧЕРЕЗ PGADMIN (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════

1. Откройте pgAdmin 4
2. Подключитесь к вашему серверу PostgreSQL
3. Найдите вашу базу данных (обычно "streamdesk")
4. Правой кнопкой на базе данных → Query Tool
5. Откройте файл create_connection_schemas_tables.sql
6. Скопируйте весь SQL код из файла
7. Вставьте в Query Tool
8. Нажмите Execute (F5)

Готово! ✅

═══════════════════════════════════════════════════════════════
  СПОСОБ 2: ЧЕРЕЗ PSQL (КОМАНДНАЯ СТРОКА)
═══════════════════════════════════════════════════════════════

1. Откройте командную строку (CMD) или PowerShell
2. Перейдите в папку проекта:
   cd D:\StreamDesk
3. Выполните команду:
   psql -U postgres -d streamdesk -f create_connection_schemas_tables.sql
4. Введите пароль PostgreSQL при запросе

Готово! ✅

═══════════════════════════════════════════════════════════════
  СПОСОБ 3: ВРУЧНУЮ ЧЕРЕЗ PSQL
═══════════════════════════════════════════════════════════════

1. Откройте SQL Shell (psql) из меню Пуск
2. Подключитесь к базе данных:
   \c streamdesk
3. Откройте файл create_connection_schemas_tables.sql
4. Скопируйте весь SQL код
5. Вставьте в psql и нажмите Enter

Готово! ✅

═══════════════════════════════════════════════════════════════
  ПРОВЕРКА
═══════════════════════════════════════════════════════════════

После создания таблиц проверьте, что они созданы:

В psql выполните:
\dt connection_schemas
\dt connection_schema_components
\dt vmix_scheduler_events

Должны появиться все три таблицы.
